# 使用指南

## 检索和选择

从[网站首页](https://embodieddataatlas.com/)点击“开始使用”，输入名称或研究关键词，或选择研究任务。任务入口会带入预设筛选条件，可继续调整。

在数据集详情中核对任务适用性、机器人与环境、模态、监督信号、规模单位、许可与访问要求。未知字段代表尚未明确核实，并非该能力不存在。

## 对比与引用

将候选加入对比清单，逐项核对实验所需条件。规模指标只有单位一致时才可直接比较。下载和使用前，重新检查官方来源的最新条款；引用优先采用详情提供的原始论文信息。

主题相关论文、引用文献和实际使用证据分别展示。论文引用关系不证明作者实际使用过某数据集，也不能直接作为使用率。

## 反馈

通过[反馈模板](https://github.com/WUJIAHAO-HKU/Embodied-Data-Atlas/issues/new/choose)提交问题。附上页面地址、复现步骤或官方来源，可帮助维护者核查。不要上传未获授权的数据、凭证或个人隐私。

公开仓库只提供项目文档与反馈入口。网站的开发源码和构建流程在私有仓库维护。
